# FarmRent

A farm equipment rental platform that connects farmers with equipment owners in Nigeria. Built for Domsal & Bonks Nigeria Limited.

**Live demo:** https://farmrent-ds.vercel.app

## What it does
- Browse equipment available for rent, with price per day and location
- View equipment details and start a booking request
- Equipment owners can list their own machines
- Agro products section for farming resources
- Login, sign up and profile pages
- Light and dark mode
- Responsive on phone, tablet and desktop, with a mobile menu
- About, Help Center, Privacy and Terms pages

## Pages
Home, Equipment, Agro Products, List Equipment, About, Help, Profile, Login, Sign Up, Privacy, Terms

## Built with
HTML, CSS, JavaScript . Hosted on Vercel.
 backend is in process
 

## Project status
This is a front-end build. Login, sign up and bookings work as screens in the browser, but there is no backend yet.

Planned next:
- Backend with Node.js, Express and MongoDB
- Real user accounts and authentication
- Saving equipment listings and bookings to a database
- Online payments

## Run locally
1. Download or clone this repository
2. Open `index.html` in your browser, or use the Live Server extension in VS Code
